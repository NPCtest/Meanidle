# 🎌 Meanidle

Welcome to **Meanidle**, a Wordle-inspired daily guessing game for Anime and Manga fans! Test your knowledge by guessing characters based on their unique stats, traits, and quotes.

## 🎮 Included Games

### 🏐 Haikyuudle
Guess characters from the *Haikyuu!!* universe!
* Compares character stats like Age, Height, Position, and Team.
* Features high-quality images and a slick custom autocomplete menu.

### 🔫 Sakamotodle
Guess characters from the hit manga *Sakamoto Days*!
* **Classic Mode:** Find the target character by matching attributes like Age, Hair Color, Occupation, Affiliation, and First Arc Appearance.
* **Quotes Mode:** Read an iconic quote from the series and guess which character said it! (Includes an integrated hint system that reveals the arc the character debuted in).

## ✨ Features
* **Smart Autocomplete:** Start typing a character's name to see their portrait and quickly select them. Automatically hides characters you've already guessed during the round.
* **Stat Comparisons:** Colors indicate if you are close (e.g., Green for a perfect match, Red for a miss).
* **Fully Offline:** All character images and data are bundled locally, meaning zero reliance on external image hosting.
* **Dynamic Modals & Hints:** Responsive UI that reveals the correct answer and portrait when you win or give up.

## 🚀 How to Play

Meanidle runs entirely in the browser using HTML, CSS, and vanilla JavaScript. There is no backend server or build step required!

1. Clone or download this repository.
2. Open `index.html` in your favorite web browser.
3. Select the game you want to play from the main menu and start guessing!

## 🛠️ Built With
* HTML5
* CSS3 (Custom styling, animations, flexbox layout)
* Vanilla JavaScript (ES6 Modules, OOP Game Logic)
